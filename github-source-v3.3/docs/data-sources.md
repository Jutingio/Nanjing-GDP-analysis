2026-10-26 重新读取 GDP 表和[编者说明](https://tjj.nanjing.gov.cn/material/njnj_2025/shouye/bzsm.html)。全市 GDP 为 **18500.81** 亿元；12 个板块公布数合计 **18479.96** 亿元；差 **20.85** 亿元。代码保留全市公布数作分母，不能给某个区机械补差、按比例放大或捏造“其他地区”。差额是公开表之间的算术差，现有证据不足以确定全部成因；不能仅凭差额推断完整的 GDP 分劈流程。

年鉴说明江北新区直管区面积 388.61 平方公里，包含原高新区、化工园区以及顶山街道、葛塘街道。同一指标项下的浦口、六合数据已剔除该直管区。直管区不是第十二个行政区，也不能等同整个江北新区。当前视频只从其余九个候选区选择三区，未制作直管区几何边界。人口、GDP 等指标均须逐表确认空间和时间口径，不能先假定能配平。

`data/snapshot.json` 保留原选区雨花台、玄武、鼓楼，seed 20260911。占比是区值/同年官方全市值；只展示三区不要求三区之和等于全市。地图是 2017 年概览边界，照片为 2025 年资料图片，均不能被解释为 2024 年精确行政现状。

`data/sources/*.web-extract.txt` 是历史网页工具读取的文本摘录，不是原始 HTML；原项目记录本地抓取曾返回 403。新构建不联网、不自动重新抄录数字。快照保留 sourceId、URL、访问日期和原摘录 hash；来源测试核对原摘录与数值。公开数值不等于整页网页、排版和文本可任意再分发，因此摘录默认不提交，许可待确认。数据事实的引用说明不授予第三方材料许可证。

引用示例：南京市统计局，《南京统计年鉴2025》，表17-6，统计年度2024，访问日期2026-10-26，附上表格链接。人口、社零应分别引用其表格及实际核验日期；历史来源记录保留原日期。代码引用见 CITATION.cff，发布前补实际作者和仓库 URL，不虚构作者或 DOI。
